# Simple Interest Calculator

A Bash script that calculates simple interest based on user input.

## Features
- Takes principal, rate of interest, and time period as input
- Calculates and displays the simple interest

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Usage
1. Make the script executable:
   chmod +x simple-interest.sh
2. Run it:
   ./simple-interest.sh
3. Enter the principal, rate of interest (%), and time period (years) when prompted.

## Example
Principal: 1000, Rate: 5, Time: 2 → Simple Interest = 100.00
